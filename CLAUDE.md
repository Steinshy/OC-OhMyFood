# OhMyFood — Restaurant Menu Website

**Type:** Frontend Static Site (Multi-Page)

---

## 🎯 Project Overview

OhMyFood is an OpenClassrooms project demonstrating:

- Multi-page static website structure
- CSS animations & transitions (keyframes in `animation.css`, `loader.css`, `restaurants.css`)
- Responsive design (breakpoints at 767px, 768px, 1024px, 1440px)
- CSS custom properties for theming
- Minified CSS files linked by the pages
- PWA manifest (no service worker)
- Font Awesome icons and Google Fonts

### Key Objectives

- Master CSS animations for UI interactions
- Implement responsive multi-page layouts
- Optimize assets for fast loading
- Build accessible restaurant menus
- Practice semantic HTML structure
- Understand performance best practices

### Business Context

Customers choose a partner Paris restaurant, compose a menu in advance, then dine in (steps listed on `index.html`). No delivery, no backend.

### Site Structure

- **Restaurant Pages** (`delice.html`, `francaise.html`, `note.html`, `palette.html`) – Banner, menu sections (Entrées, Plats, Desserts), "Commander" button

### No Build Process Required

- Pages are plain HTML, CSS and one JS file; no bundler or framework
- Viewing the site needs no build step
- After editing CSS, run `pnpm run build:css` to regenerate the `.min.css` files the pages link (CI checks they are in sync)
- Hosted as static files (GitHub Pages URL in `sitemap.xml`)

## 🎨 CSS Architecture

### Main Files

- `style.css` – `:root` variables, reset, header, booking, restaurant cards, heart icon, footer, responsive rules
- `restaurants.css` – Restaurant page banner, menu container, menu items, and its own 768px and 1024px breakpoints
- `animation.css` – Shared keyframes (`hideLoader`, `fadeIn`, `slideUpFadeIn`) and the reduced-motion rule
- `loader.css` – Loading overlay and spinner (`loader-spin`) with a reduced-motion rule

### CSS Organization

- `style.css` section order: `:root` variables (colors, typography, spacing, layout, shadows), Reset, Header, Banner Location, Booking Section and Booking Card, Restaurants, Heart Icon, Footer, Responsive Design
- Variables use `--color-*`, `--font-*`, `--fs-*`, `--space-xs` to `--space-3xl`, and `--size-*`
- Example: `--color-primary: #9356dc;` and `--color-secondary: #ff79da;`

## ✨ CSS Animations & Interactions

### Key Animations

**1. Menu Item Hover Effect** (`restaurants.css`)

- `.menu_items:hover` raises `box-shadow` to `--shadow-medium` and widens `.menu_item_content` to 60%
- `.check_icon i` rotates 360deg on hover or `:focus-within`, 0.3s cubic-bezier(0.4, 0, 0.2, 1)

**2. Heart Icon** (`style.css`)

- `.custom_heart` is a decorative Font Awesome `<i>`, not a button, with no JavaScript behavior
- On `:hover` and `:focus-visible` its color changes to `--color-primary` and its text stroke is removed (0.3s)

**3. Loading Overlay** (`loader.css`, `animation.css`)

- `.loader_container` runs `hideLoader` for 0.2s after a 0.8s delay, then stays hidden (`forwards`)
- `.loader` spins with `loader-spin` (0.9s, linear, infinite)

**4. Page Entrance** (`style.css`, `restaurants.css`)

- `main` fades in with `fadeIn` (0.2s, 0.8s delay)
- `.menu_sections` and `.menu_items` slide up with `slideUpFadeIn` (0.5s ease-out); menu items are staggered with `nth-child` delays from 1.2s to 1.8s

### Transitions

- **Buttons:** `.btn` and `.scroll-to-top` transition `transform`, `box-shadow` and `opacity` over 0.3s, and lift 2px on hover or focus
- **Cards:** `.restaurant_card` and `.menu_items` transition `box-shadow` (0.3s); `.restaurant_card:hover` lifts 2px
- **Colors:** `.custom_heart` transitions `color` over 0.3s with the default easing

## 📱 Responsive Design

### Breakpoints

```css
/* style.css */
@media (width <= 767px) {
  /* footer stacks in a column */
}
@media (width >= 768px) {
  /* 2-column restaurant cards, 3-column booking steps */
}
@media (width >= 1024px) {
  /* body max-width 1400px, menu container 85% */
}
@media (width >= 1440px) {
  /* body max-width 1600px */
}

/* restaurants.css */
@media (width >= 768px) {
  /* banner 280px tall */
}
@media (width >= 1024px) {
  /* banner 300px tall, 2-column restaurant cards */
}
```

### Responsive Strategy

- **Mobile (< 768px):** Single-column restaurant cards, footer links stacked
- **Tablet (768px+):** 2-column restaurant cards, 3-column booking steps
- **Desktop (1024px+):** Body capped at 1400px, menu container 85% wide
- **Large Desktop (1440px+):** Body capped at 1600px

### Viewport Meta Tag

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
```

### Icon Library

- **Font Awesome 6.7.2** (CDN, with SRI `integrity`) – location, heart, check, arrow, footer icons
- **Logo:** `favicons/ohmyfood@2x.svg` (no separate custom icon set)

### Font Optimization

- **Google Fonts:** Roboto (300, 400, 500, 700) and Shrikhand, with `display=swap`
- **Loading:** `preconnect` to fonts.googleapis.com and fonts.gstatic.com; the stylesheet is a normal `<link rel="stylesheet">` (render-blocking, not async)

## ♿ Accessibility

### Semantic HTML

```html
<header><nav class="header_nav" aria-label="Navigation principale">…</nav></header>
<main id="main-content">…</main>
<footer><nav aria-label="Liens utiles">…</nav></footer>

<article class="restaurant_card" aria-labelledby="palette-title">
  <h3 id="palette-title">La palette du goût</h3>
</article>
```

### ARIA & Labels

- Loader: `role="status"` and `aria-live="polite"` on `.loader_container`
- All Font Awesome `<i>` icons, including the heart, have `aria-hidden="true"`
- Restaurant cards use `aria-labelledby` and `aria-describedby`; the card link has an `aria-label`
- Back link and scroll-to-top button have `aria-label`

### Color Contrast (computed)

- Body text `#000` on `#fff`: 21:1
- Primary `#9356dc` on `#fff`: 4.56:1 (passes WCAG AA for normal text)

## 🚀 Development & Deployment

### Development

```bash
# No build step to view the site: open index.html in a browser
```

### Optimization (Optional)

```bash
pnpm install          # Dev tooling: html-validate, stylelint, prettier, lightningcss-cli
pnpm run lint         # html-validate on *.html, then stylelint on *.css (skips *.min.css)
pnpm run format       # Prettier --write on html, css, json, md
pnpm run format:check # Same check CI runs
pnpm run build:css    # Regenerate css/*.min.css (style, loader, animation, restaurants)
pnpm run update:check # npm-check-updates report (update:interactive, update:all also exist)
```

### Production Deployment

- GitHub Pages serves the site (URL in `sitemap.xml` and `README.md`); Pages settings are not in the repo
- CI (`.github/workflows/ci.yml`) runs on push to `main` and on pull requests: lint, format check, and a check that `css/` minified files match `build:css` output
- Known issue: CI installs with `npm ci` and uses `cache: 'npm'`, but the repo has only `pnpm-lock.yaml`

## 🐛 Common Issues & Solutions

| Issue                         | Solution                                                                                                                        |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| Animations too slow           | Check durations in `animation.css`, `loader.css`, `restaurants.css` (e.g. `slideUpFadeIn` is 0.5s)                              |
| Layout broken on mobile       | Check viewport meta tag, test in DevTools                                                                                       |
| Fonts not loading             | Verify Google Fonts link in `<head>`, check network tab                                                                         |
| Images stretched              | `object-fit: cover` is already set on `img` (style.css) and `.main_banner_container img` (restaurants.css); check for overrides |
| Heart icon does nothing       | Heart is a decorative icon with no click handler; `js/main.js` only drives `#scrollToTopBtn`                                    |
| PWA not installing            | Check manifest.json and that the icon files in `favicons/` exist                                                                |
| CI "minified CSS" check fails | Run `pnpm run build:css` and commit the regenerated `css/*.min.css`                                                             |
